# УТЭК — приёмная комиссия

Стартовая версия сайта рейтингов абитуриентов Уфимского торгово-экономического колледжа.

## Быстрый запуск через Makefile

В PowerShell из корня проекта:

```powershell
make help
make setup
make infra-up
make migrate
```

Дальше откройте два окна терминала и выполните в них `make api` и `make web`. Сайт будет доступен по адресу, который выведет Vite (обычно `http://localhost:5173`). Полная проверка проекта: `make test`.

> На Windows нужен GNU Make. Если команда `make` не найдена, можно установить его через `winget install GnuWin32.Make` либо пользоваться командами из следующего раздела напрямую.

## Запуск без Makefile

1. Запустите инфраструктуру: `docker compose up -d`.
2. В одном терминале: `cd backend; go run .`.
3. В другом: `cd frontend; npm install; npm run dev`.
4. Откройте адрес, который выведет Vite (обычно `http://localhost:5173`).

Схема PostgreSQL находится в `backend/migrations`. В неё уже заложены СНИЛС, до трёх заявлений на абитуриента, единственный оригинал и снимки опубликованных списков. Подключение API к этой схеме и админ-панель добавляются следующим этапом.
